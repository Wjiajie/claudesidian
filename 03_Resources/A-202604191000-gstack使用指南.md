# gstack 使用指南

## 什么是 gstack

gstack 是基于 [garrytan/gstack](https://github.com/garrytan/gstack) 安装的一套 AI 技能系统，为 Claude Code 提供结构化的专业工作流。它包含 40+ 技能（skills），覆盖从产品构思到代码开发、测试、部署、复盘的完整开发周期。

核心理念：**Boil the Lake**（煮沸湖泊）—— 当 AI 让边际成本接近零时，始终做完整的事情。捷径是给未来的自己挖坑。

## 日常使用建议

### 新手入门路径

建议从以下三个 skill 开始：

1. **`/investigate`** — 遇到 bug 时使用，系统性调查问题根因
2. **`/qa`** — 需要测试网站或 Web 应用时使用
3. **`/ship`** — 准备发布代码时使用，自动完成整个发布流程

### 按场景选择

**想验证一个 Web 应用是否正常工作：**
```bash
/qa
```

**遇到了 bug 需要调查：**
```bash
/investigate
```

**准备发布新功能：**
```bash
/ship
```

**需要别人对你的方案提意见：**
```bash
/office-hours   # 产品方向
/plan-eng-review  # 技术方案
/design-review    # 视觉设计
```

**保存当前工作进度，之后继续：**
```bash
/context-save
```
（之后用 `/context-restore` 恢复）

### 主动推荐（Proactive Mode）

gstack 默认会**主动推荐**可能帮助你的 skill。例如：
- 你说 "这个功能不工作" → 自动推荐 `/investigate`
- 你说 "怎么部署？" → 自动推荐 `/ship`
- 你说 "看看这周做了什么" → 自动推荐 `/retro`

如果你不需要主动推荐，运行：
```bash
gstack-config set proactive false
```

## 配置选项

gstack 的行为可以通过 `gstack-config` 调整：

```bash
# 查看所有配置
gstack-config list

# 关闭遥测
gstack-config set telemetry off

# 关闭主动推荐
gstack-config set proactive false

# 切换写作风格（default = ELI10 简单风格，terse = 精简风格）
gstack-config set explain_level terse
```

## Skill 路由规则

gstack 支持在 `CLAUDE.md` 中添加路由规则，让 AI 自动调用合适的 skill。你可以通过以下方式添加：

1. 运行任意 gstack skill，AI 会询问是否添加路由规则
2. 或者手动添加到 `CLAUDE.md`：

```markdown
## Skill routing

When the user's request matches an available skill, ALWAYS invoke it using the Skill
tool as your FIRST action. Do NOT answer directly, do NOT use other tools first.

Key routing rules:
- Product ideas, "is this worth building", brainstorming → invoke office-hours
- Bugs, errors, "why is this broken", 500 errors → invoke investigate
- Ship, deploy, push, create PR → invoke ship
- QA, test the site, find bugs → invoke qa
- Code review, check my diff → invoke review
- Update docs after shipping → invoke document-release
- Weekly retro → invoke retro
- Design system, brand → invoke design-consultation
- Visual audit, design polish → invoke design-review
- Architecture review → invoke plan-eng-review
- Save progress, save state, save my work → invoke context-save
- Resume, where was I, pick up where I left off → invoke context-restore
- Code quality, health check → invoke health
```
