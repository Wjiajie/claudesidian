# Obsidian CLI 速查表

> Obsidian 1.12+ 内置官方 CLI 配合 PowerShell wrapper 的完整使用指南。
> **必读**：执行任何写入操作前**先看 [§5 已知问题](#5-已知问题)**，再决定是否要 `-DryRun`。

## 0. 快速开始

```powershell
# 加载 wrapper (PS 5.1+)
$wrapper = "06_Metadata/工具脚本/obsidian-cli.ps1"

# 读一个文件
& $wrapper read 'file=06_Metadata/README.md'

# 搜索 + JSON 美化
& $wrapper search 'query=obsidian' 'format=json' -Json

# 写一个 frontmatter 字段 (text)
& $wrapper set-property -File '00_Inbox/2025-12-29.md' -Name 'tags' -Value 'demo' -Type text

# 写一个 frontmatter 字段 (list)
& $wrapper set-property -File '00_Inbox/2025-12-29.md' -Name 'tags' -Value 'a, b, c' -Type list

# 危险操作前先看会发生什么
& $wrapper delete 'path=some/old/note.md' -DryRun
```

## 1. Wrapper 速查

完整 wrapper 在 `06_Metadata/工具脚本/obsidian-cli.ps1`。它解决 3 个原生 obsidian CLI 的坑：
1. 静默过滤启动 banner（每次 stdout 头部两行噪音）
2. 强制 UTF-8 编码捕获 stdout（避免 PS 5.1 ANSI 编码吞中文）
3. `-DryRun` 安全网（agent 操作知识库前先 dry-run 一次再确认）
4. 额外提供 `set-property` 子命令（绕过 1.12.7 `property:set` 命令的 bug）

| 开关 | 作用 |
|------|------|
| `-DryRun` | 只打印命令，不执行（**任何写入操作前都应先试**） |
| `-NoLog` | 跳过日志写入 |
| `-NoBanner` | 不过滤 banner（调试用） |
| `-Json` | 把输出解析为 JSON 并美化 |
| `-Vault <name>` | 显式指定 vault（单 vault 可省） |

日志自动写到 `06_Metadata/工具脚本/logs/obsidian-cli-yyyy-MM-dd.log`。

## 2. 原生 obsidian CLI 命令速查

### 2.1 读取类

| 命令 | 用途 | 例 |
|------|------|-----|
| `vault` | vault 信息（name/path/files/folders/size） | `obsidian vault` |
| `read` | 读文件内容 | `obsidian read file=06_Metadata/README.md` |
| `search` | 全文搜索（默认 tsv，加 `format=json`） | `obsidian search query=obsidian format=json` |
| `search:context` | 带匹配行上下文的搜索 | `obsidian search:context query=AI` |
| `backlinks` | 反向链接（指向某笔记的链） | `obsidian backlinks file=2025-12-29` |
| `links` | 出链（某笔记里的所有链） | `obsidian links file=2025-12-29` |
| `outline` | 笔记大纲 | `obsidian outline file=2025-12-29 format=md` |
| `tags` | 全库标签列表 | `obsidian tags format=json` |
| `properties` | 全库 frontmatter 字段列表 | `obsidian properties format=json` |
| `unresolved` | 悬空链接（指向不存在笔记） | `obsidian unresolved format=json` |
| `orphans` | 孤立笔记（无入链） | `obsidian orphans` |
| `deadends` | 死链笔记（无出链） | `obsidian deadends` |
| `wordcount` | 字数统计 | `obsidian wordcount file=2025-12-29 words` |
| `recents` | 最近打开文件 | `obsidian recents` |

### 2.2 写入类

| 命令 | 用途 | 例 |
|------|------|-----|
| `create` | 新建文件 | `obsidian create name="new.md" content="# init" template="Daily Note Template"` |
| `append` | 追加内容（默认换行，`inline` 不换行） | `obsidian append content="- new item" file=2025-12-29` |
| `prepend` | 前置内容 | `obsidian prepend content="## summary" file=2025-12-29` |
| `delete` | 删除文件（`permanent` 跳过回收站） | `obsidian delete path=old.md permanent` |
| `rename` | 重命名 | `obsidian rename name=新名.md file=旧名.md` |
| `move` | 移动到其他文件夹 | `obsidian move to=02_Areas file=old.md` |
| `task` | 改任务状态（`toggle`/`done`/`todo`） | `obsidian task ref="2025-12-29.md:3" toggle` |
| `bookmark` | 加书签 | `obsidian bookmark file=2025-12-29` |
| `daily:append` | 追加到当天 daily note | `obsidian daily:append content="- check"` |

> ⚠️ **写入操作需要 Obsidian app 运行**（IPC 通道）。Obsidian 关闭时所有写命令都会失败。

### 2.3 高级 / 自动化

| 命令 | 用途 | 备注 |
|------|------|------|
| `command id=<cmd-id>` | 执行任意 Obsidian 命令面板命令 | 杀手锏，触发第三方插件 |
| `eval code=<js>` | 在 Obsidian 上下文执行 JS | 见 §3 |
| `plugin:enable` / `plugin:disable` | 启停插件 | `obsidian plugin:enable id=dataview` |
| `theme:set` | 切主题 | `obsidian theme:set name=Things` |
| `tabs` | 列出所有 tab | `obsidian tabs` |
| `daily:path` | 当天 daily note 路径 | `obsidian daily:path` |

完整命令列表：`obsidian help` 或 `obsidian help <command>` 看具体参数。

## 3. set-property 子命令（绕过 1.12.7 property:set bug）

`obsidian property:set` 在 1.12.7 上对**所有** frontmatter 字段都不生效（多次尝试未触发文件写入）。wrapper 提供了 `set-property` 子命令，通过 `eval` 走 Obsidian 原生 `app.fileManager.processFrontMatter` API 解决。

### 3.1 调用方式

```powershell
& $wrapper set-property `
    -File '00_Inbox/2025-12-29.md' `
    -Name 'tags' `
    -Value 'smoke, test, list-type' `
    -Type list
```

### 3.2 支持的 Type

| Type | 用途 | Value 格式 |
|------|------|------------|
| `text` | 单字符串 | 直接给值（默认值） |
| `list` | YAML 列表 | 英文逗号分隔，如 `'a, b, c'` |
| `number` | 数字 | 字符串数字 |
| `checkbox` | 布尔 | `true` / `false` |
| `date` | 日期 | `2026-06-06` |
| `datetime` | 日期时间 | `2026-06-06 18:00` |

### 3.3 实现原理

```javascript
// wrapper 内部生成的 IIFE
(function(){
  var f = app.vault.getAbstractFileByPath(String.fromCharCode(...));  // 文件路径（无引号注入）
  if (!f) { return 'NOT_FOUND' }
  app.fileManager.processFrontMatter(f, function(fm){
    var n = String.fromCharCode(...);   // 字段名
    var raw = String.fromCharCode(...); // 字段值
    var lb = String.fromCharCode(91);   // '['
    fm[n] = raw.charAt(0) === lb ? JSON.parse(raw) : raw;  // list 走 JSON.parse
  });
  return 'OK'
})()
```

所有字符串用 `String.fromCharCode` 注入，**完全不出现引号**，避免 Windows 命令行解析时引号嵌套问题。

## 4. 实战模式

### 4.1 知识库搜索并打印文件

```powershell
# 找到所有提到 "obsidian" 的笔记
$files = & $wrapper search 'query=obsidian' 'format=json' -Json | ConvertFrom-Json
$files | ForEach-Object { Write-Host $_ }
```

### 4.2 改 frontmatter parent 字段（批量）

```powershell
# 把所有 00_Inbox 下的笔记 parent 改成 "闪念胶囊收集"
$inbox = & $wrapper files 'folder=00_Inbox' 'total'  # 获取文件数
# 逐个调用 set-property
foreach ($f in (& $wrapper files 'folder=00_Inbox' 'format=json' -Json | ConvertFrom-Json)) {
    & $wrapper set-property -File $f -Name 'parent' -Value '[[闪念胶囊收集]]' -Type text
    Start-Sleep -Seconds 1  # 避免 Obsidian 内部状态冲突
}
```

### 4.3 找孤立笔记 + 打印建议

```powershell
$orphans = & $wrapper orphans 'format=json' -Json | ConvertFrom-Json
$orphans | ForEach-Object { Write-Host "Orphan: $_" }
```

### 4.4 创建笔记时套用模板

```powershell
& $wrapper create `
    -Name '2026-06-07.md' `
    -Content '' `
    -Template 'Daily Note Template' `
    -Folder '00_Inbox'
```

## 5. 已知问题

### 5.1 Obsidian 1.12.7 property:set 命令 bug

`obsidian property:set` 在 1.12.7 上**对所有 frontmatter 字段都不生效**（多次测试，exit code 0 但文件无变化）。**用 wrapper 的 `set-property` 子命令绕过**。

### 5.2 set-property 快速连续调用可能失败

Obsidian 内部状态在多次快速 `processFrontMatter` 调用时会冲突（看起来调用了但写入没持久化）。**建议每次调用间隔 1 秒**，或在批处理中加 `Start-Sleep -Seconds 1`。

### 5.3 写入需要 Obsidian 打开

CLI 实际是 IPC 通道，**Obsidian app 必须运行**才能用 `create`/`append`/`property:set` 等写命令。读取类（`vault`/`read`/`search`）在 Obsidian 关闭时仍然可以走缓存响应（取决于实现）。

### 5.4 中文输出在 PS 5.1 控制台显示乱码

这是 **Windows 控制台代码页**问题，不是数据问题。数据本身是 UTF-8 正确的。修复方法（任选）：
- `chcp 65001` 切换到 UTF-8 代码页
- 用 Windows Terminal（默认 UTF-8）
- 把输出重定向到文件用编辑器查看

### 5.5 Installer 版本提示

每次调用 stdout 头部会出现：
```
2026-06-06 ... Loading updated app package ...
Your Obsidian installer is out of date. Please download the latest installer...
```

**wrapper 已自动过滤这两行**。如果想看原始输出加 `-NoBanner`。
要去掉这个提示本身：去 https://obsidian.md/download 装新 installer。

### 5.6 delete permanent 不一定真删

实测 `obsidian delete path=xxx permanent` 行为有时不一致。如果真要删，用 `obsidian delete path=xxx`（不带 permanent，走回收站）更稳。
